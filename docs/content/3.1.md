# 🧮 Subnetz-Berechnungen: Übungen mit Schritt-für-Schritt-Anleitung


## 📚 **Theorie: Wie funktioniert Subnetting?**

### **1. Was ist eine Subnetzmaske?**

Eine **Subnetzmaske** teilt eine IP-Adresse in zwei Teile:

- **Netzwerkanteil** (links)
- **Hostanteil** (rechts)

**Beispiel:**  
IP: `192.168.1.10`  
Subnetzmaske: `255.255.255.0` (`/24`)  
→ **Netzwerkanteil:** `192.168.1`  
→ **Hostanteil:** `.10`

---

### **2. CIDR-Notation (Classless Inter-Domain Routing)**

- **Kürzere Schreibweise** für Subnetzmasken.
- **Beispiel:**
  - `255.255.255.0` = `/24` (24 Bits für Netzwerk, 8 Bits für Hosts)
  - `255.255.0.0` = `/16` (16 Bits für Netzwerk, 16 Bits für Hosts)

---

### **3. Anzahl der Hosts berechnen**

**Formel:**

```
Anzahl Hosts = 2^(Anzahl Host-Bits) - 2
```

- **Warum -2?**
  - **1 Adresse** für das **Netzwerk selbst** (z. B. `192.168.1.0`).
  - **1 Adresse** für den **Broadcast** (z. B. `192.168.1.255`).

**Beispiel für /24:**

- Host-Bits: `32 - 24 = 8`
- Anzahl Hosts: `2^8 - 2 = 256 - 2 = 254`

## 🧠 **Anleitung: Wie berechnet man das?**

---

### **1. Subnetzmaske → CIDR-Notation**

**Schritt-für-Schritt:**

1. **Subnetzmaske in Binär umwandeln**
  Beispiel: `255.255.255.128`  
   → `11111111.11111111.11111111.10000000`
2. **Anzahl der aufeinanderfolgenden 1en zählen**
  → 25 Einsen → **/25**

**Beispiel:**


| **Subnetzmaske** | **Binär**                           | **CIDR** |
| ---------------- | ----------------------------------- | -------- |
| 255.0.0.0        | 11111111.00000000.00000000.00000000 | /8       |
| 255.255.0.0      | 11111111.11111111.00000000.00000000 | /16      |
| 255.255.255.128  | 11111111.11111111.11111111.10000000 | /25      |


---

---

### **2. CIDR-Notation → Subnetzmaske**

**Schritt-für-Schritt:**

1. **Anzahl der Netzwerk-Bits** (CIDR-Wert) bestimmen.
  Beispiel: `/25` → 25 Bits für Netzwerk.
2. **Subnetzmaske in Binär erstellen**
  - 25 Einsen + 7 Nullen → `11111111.11111111.11111111.10000000`
3. **Binär in Dezimal umwandeln**
  → `255.255.255.128`

**Beispiel:**


| **CIDR** | **Binär**                           | **Subnetzmaske** |
| -------- | ----------------------------------- | ---------------- |
| /24      | 11111111.11111111.11111111.00000000 | 255.255.255.0    |
| /26      | 11111111.11111111.11111111.11000000 | 255.255.255.192  |


---

---

### **3. Anzahl Hosts berechnen**

**Schritt-für-Schritt:**

1. **Anzahl der Host-Bits** berechnen:
  `32 - CIDR-Wert`  
   Beispiel: `/24` → `32 - 24 = 8 Host-Bits`
2. **Anzahl der Hosts** berechnen:
  `2^(Host-Bits) - 2`  
   Beispiel: `2^8 - 2 = 256 - 2 = 254`

**Warum -2?**

- **1 Adresse** für das **Netzwerk** (z. B. `192.168.1.0`).
- **1 Adresse** für den **Broadcast** (z. B. `192.168.1.255`).

### **📝 Aufgabe 6: Netzwerkaufteilung**

**Szenario:**  
Du hast das Netzwerk `192.168.1.0/24` und möchtest es in **4 gleich große Subnetze** aufteilen.

**Fragen:**

1. Welche **CIDR-Notation** hat jedes Subnetz?
2. Wie viele **Hosts** hat jedes Subnetz?
3. Gib die **Netzwerkadressen** und **Broadcast-Adressen** der Subnetze an.

??? success "Lösung:"

    ```
    **1. CIDR-Notation:**
    - Ursprüngliches Netzwerk: `/24` (256 Adressen).
    - Aufteilung in 4 Subnetze → **/26** (64 Adressen pro Subnetz).

    **2. Anzahl Hosts:**
    - `/26` → `2^(32-26) - 2 = 2^6 - 2 = 64 - 2 = 62 Hosts`.

    **3. Netzwerkadressen und Broadcast-Adressen:**
    | **Subnetz** | **Netzwerkadresse** | **Broadcast-Adresse** | **Host-Bereich** |
    |-------------|----------------------|-----------------------|------------------|
    | Subnetz 1   | 192.168.1.0/26        | 192.168.1.63          | 192.168.1.1 – 192.168.1.62 |
    | Subnetz 2   | 192.168.1.64/26       | 192.168.1.127         | 192.168.1.65 – 192.168.1.126 |
    | Subnetz 3   | 192.168.1.128/26      | 192.168.1.191         | 192.168.1.129 – 192.168.1.190 |
    | Subnetz 4   | 192.168.1.192/26      | 192.168.1.255         | 192.168.1.193 – 192.168.1.254 |
    ```

### **📝 Aufgabe 7: Benötigte Subnetzgröße berechnen**

**Szenario:**  
Du brauchst ein Subnetz für **50 Hosts**. Welche **kleinste mögliche CIDR-Notation** kannst du verwenden?

**Frage:** Welche CIDR-Notation wählst du und warum?

??? success "Lösung:"

```
**Berechnung:**
- **Anforderung:** 50 Hosts → `2^n - 2 ≥ 50` → `n = 6` (2^6 - 2 = 62).
- **CIDR-Notation:** `32 - 6 = 26` → **/26**.

**Antwort:**
- **/26**, weil es **62 Hosts** unterstützt (die kleinste CIDR, die ≥ 50 Hosts erlaubt).
```

## 🎓 **Zusammenfassung: Die wichtigsten Formeln**


| **Berechnung**               | **Formel**                           | **Beispiel**                                                                    |
| ---------------------------- | ------------------------------------ | ------------------------------------------------------------------------------- |
| **CIDR → Host-Bits**         | `32 - CIDR`                          | `/24` → `32 - 24 = 8`                                                           |
| **Host-Bits → Anzahl Hosts** | `2^(Host-Bits) - 2`                  | `8 Host-Bits` → `2^8 - 2 = 254`                                                 |
| **Subnetzmaske → CIDR**      | Anzahl der **1en** in Binär          | `255.255.255.0` → `11111111.11111111.11111111.00000000` → **24 Einsen** → `/24` |
| **CIDR → Subnetzmaske**      | `CIDR` Einsen + `(32 - CIDR)` Nullen | `/25` → `11111111.11111111.11111111.10000000` → `255.255.255.128`               |
