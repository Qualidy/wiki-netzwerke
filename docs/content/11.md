# WordPress mit Docker auf einer VM installieren

---

## 📌 Einführung

### **Was ist Docker?**

Docker ist eine **Plattform zur Isolierung und Verwaltung von Anwendungen in Containern**.  
Stell dir Docker wie **virtuelle Behälter** vor, in denen Anwendungen (z. B. WordPress, MySQL) **isoliert und unabhängig** vom Host-System laufen.

#### **Vorteile von Docker:**

✅ **Isolation:** Jede Anwendung läuft in einem **eigenen Container** und beeinflusst andere nicht.  
✅ **Portabilität:** Container laufen auf **jedem System mit Docker** (Linux, Windows, macOS).  
✅ **Einfache Verwaltung:** Container können mit einem Befehl **gestartet, gestoppt oder gelöscht** werden.  
✅ **Ressourceneffizienz:** Container teilen sich den **Kernel des Hosts** und sind **leichter als VMs**.

#### **Nachteile von Docker:**

❌ **Kein vollständiges Betriebssystem:** Container teilen sich den Kernel des Hosts (im Gegensatz zu VMs).  
❌ **Sicherheit:** Container sind **nicht so isoliert wie VMs** (z. B. bei Kernel-Schwachstellen).

---

### **Was ist WordPress?**

WordPress ist ein **Content-Management-System (CMS)**, mit dem du **Webseiten und Blogs** erstellen kannst.

- **Datenbank:** WordPress benötigt eine **MySQL- oder MariaDB-Datenbank**.
- **Webserver:** WordPress läuft auf einem **Webserver** (z. B. Apache oder Nginx).

## 🛠️ Vorbereitung der VM

### **1. VM erstellen**

Erstelle eine **Ubuntu Server-VM** (z. B. in VirtualBox oder auf einem Cloud-Server) mit:

- **2 GB RAM**
- **2 CPU-Kerne**
- **20 GB Festplatte**

### **2. System aktualisieren**

```bash
sudo apt update && sudo apt upgrade -y
```

### **3. Docker installieren**

```bash
# System aktualisieren
sudo apt update && sudo apt upgrade -y

# Docker installieren (aus den Ubuntu-Repositories)
sudo apt install docker.io docker-compose -y

# Docker starten und aktivieren
sudo systemctl start docker
sudo systemctl enable docker

# Prüfen, ob Docker läuft
sudo docker run hello-world
```

**Erwartete Ausgabe:**

```
Hello from Docker!
This message shows that your installation appears to be working correctly.
...
```

### **4. Docker Compose installieren**

Docker Compose ist ein Tool, um **mehrere Container** (z. B. WordPress + MySQL) mit einer Konfigurationsdatei zu verwalten.

```bash
# Docker Compose herunterladen
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose

# Ausführbar machen
sudo chmod +x /usr/local/bin/docker-compose

# Prüfen, ob Docker Compose installiert ist
docker-compose --version
```

**Erwartete Ausgabe:**

```
docker-compose version 1.29.2, build 5be7ff8
```

## 🚀 WordPress mit Docker installieren

### **1. Projektverzeichnis erstellen**

```bash
mkdir wordpress-docker
cd wordpress-docker
```

### **2. `docker-compose.yml` erstellen**

Erstelle eine Datei namens `docker-compose.yml` mit folgendem Inhalt:

```yaml
version: '3.8'

services:
  # MySQL-Datenbank
  db:
    image: mysql:5.7
    volumes:
      - db_data:/var/lib/mysql
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: dein_sicheres_passwort
      MYSQL_DATABASE: wordpress
      MYSQL_USER: wordpress
      MYSQL_PASSWORD: wordpress_passwort

  # WordPress
  wordpress:
    depends_on:
      - db
    image: wordpress:latest
    volumes:
      - wordpress_data:/var/www/html
    ports:
      - "80:80"
    restart: always
    environment:
      WORDPRESS_DB_HOST: db:3306
      WORDPRESS_DB_USER: wordpress
      WORDPRESS_DB_PASSWORD: wordpress_passwort
      WORDPRESS_DB_NAME: wordpress

volumes:
  db_data:
  wordpress_data:
```

**Erklärung der `docker-compose.yml`:**


| **Teil**                  | **Beschreibung**                                              |
| ------------------------- | ------------------------------------------------------------- |
| `version: '3.8'`          | Version der Docker Compose-Syntax.                            |
| `services:`               | Definiert die Container (Dienste).                            |
| `db:`                     | MySQL-Datenbank-Container.                                    |
| `image: mysql:5.7`        | Verwendet das **MySQL 5.7-Image** aus Docker Hub.             |
| `volumes:`                | Speichert Daten **dauerhaft** (auch nach Container-Neustart). |
| `environment:`            | Umgebungsvariablen für die Konfiguration (z. B. Passwörter).  |
| `wordpress:`              | WordPress-Container.                                          |
| `image: wordpress:latest` | Verwendet das **neueste WordPress-Image**.                    |
| `ports: - "80:80"`        | Mappt **Port 80 des Containers** auf **Port 80 des Hosts**.   |
| `depends_on: - db`        | WordPress startet **erst nach der Datenbank**.                |


### **3. WordPress starten**

```bash
docker-compose up -d
```

**Was passiert hier?**

- Docker lädt die **Images** (WordPress und MySQL) von Docker Hub herunter.
- Docker erstellt **zwei Container** (WordPress und MySQL).
- Docker startet die Container **im Hintergrund** (`-d` = detached mode).

**Prüfen, ob die Container laufen:**

```bash
docker-compose ps
```

**Erwartete Ausgabe:**

```
      Name                     Command               State           Ports
-----------------------------------------------------------------------------------
wordpress-docker_db_1    docker-entrypoint.sh mysqld    Up      3306/tcp
wordpress-docker_wordpress_1   docker-entrypoint.sh apach ...   Up      0.0.0.0:80->80/tcp
```

### **4. WordPress im Browser aufrufen**

Öffne einen Browser und rufe die **IP-Adresse deiner VM** auf:

```
http://DEINE_VM_IP
```

**Erwartet:**

- Du siehst die **WordPress-Installationsseite**.
- Wähle eine Sprache und folge den Anweisungen.

## 📝 WordPress konfigurieren

### **1. WordPress-Installation abschließen**

1. **Sprache auswählen** → **Weiter**.
2. **Datenbankverbindung prüfen** → WordPress sollte die Datenbank automatisch erkennen.
3. **Seiteninformationen eingeben:**
  - **Seitentitel:** Mein WordPress-Blog
  - **Benutzername:** admin (oder ein sicherer Benutzername)
  - **Passwort:** ein **sicheres Passwort** (mind. 12 Zeichen)
  - **E-Mail:** deine E-Mail-Adresse
4. **Installieren** klicken.

### **2. WordPress-Dashboard aufrufen**

Nach der Installation:

- Melde dich mit deinem **Benutzernamen und Passwort** an.
- Du wirst zum **WordPress-Dashboard** weitergeleitet.

## 🔧 Docker-Befehle für die Verwaltung


| **Befehl**                   | **Beschreibung**                          |
| ---------------------------- | ----------------------------------------- |
| `docker-compose up -d`       | Startet alle Container im Hintergrund.    |
| `docker-compose down`        | Stoppt und entfernt alle Container.       |
| `docker-compose ps`          | Zeigt den Status der Container an.        |
| `docker-compose logs`        | Zeigt die Logs der Container an.          |
| `docker-compose restart`     | Startet alle Container neu.               |
| `docker ps`                  | Zeigt alle laufenden Docker-Container an. |
| `docker stop CONTAINER_NAME` | Stoppt einen bestimmten Container.        |
| `docker rm CONTAINER_NAME`   | Entfernt einen Container.                 |
| `docker images`              | Zeigt alle heruntergeladenen Images an.   |
| `docker rmi IMAGE_NAME`      | Entfernt ein Image.                       |

## 🎓 Zusammenfassung

### **Was du gelernt hast:**

✅ **Docker** ist eine Plattform für **Container**, die Anwendungen isoliert ausführen.  
✅ **Docker Compose** vereinfacht das Verwalten von **mehreren Containern** (z. B. WordPress + MySQL).  
✅ **WordPress** kann mit Docker **einfach installiert und verwaltet** werden.  
✅ **Volumes** speichern Daten **dauerhaft**, auch wenn Container neu gestartet werden.

### **Wichtige Befehle:**


| **Zweck**                     | **Befehl**                                                                                                                                          |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Docker installieren           | `sudo apt install docker-ce docker-ce-cli containerd.io`                                                                                            |
| Docker starten                | `sudo systemctl start docker`                                                                                                                       |
| Docker Compose installieren   | `sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose` |
| Container starten             | `docker-compose up -d`                                                                                                                              |
| Container stoppen             | `docker-compose down`                                                                                                                               |
| Status der Container anzeigen | `docker-compose ps`                                                                                                                                 |
| Logs anzeigen                 | `docker-compose logs`                                                                                                                               |
