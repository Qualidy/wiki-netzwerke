    📧 Tag 7: E-Mail-Server (Postfix/Dovecot) - Einfach erklärt¶

    📚 Theorie – ganz einfach erklärt¶

    1. Wie funktioniert E-Mail?¶

    Stell dir vor, du schickst einen Brief:

    1. Du schreibst den Brief und wirfst ihn in einen Briefkasten (E-Mail-Client wie Outlook oder Thunderbird).
    2. Der Postbote (SMTP-Server, z. B. Postfix) holt den Brief ab und bringt ihn zum Postamt (E-Mail-Server).
    3. Das Postamt schickt den Brief zum Postamt des Empfängers (über das Internet).
    4. Der Postbote des Empfängers (IMAP/POP3-Server, z. B. Dovecot) legt den Brief in den Briefkasten des Empfängers (E-Mail-Postfach).
    5. Der Empfänger holt den Brief aus seinem Briefkasten ab (mit einem E-Mail-Client).

    E-Mail-Protokolle:

    Protokoll Wofür? Port
    SMTP (Simple Mail Transfer Protocol) Versenden von E-Mails. 25, 587 (mit TLS)
    IMAP (Internet Message Access Protocol) Empfangen und Verwalten von E-Mails (bleiben auf dem Server). 143, 993 (mit SSL)
    POP3 (Post Office Protocol) Empfangen von E-Mails (werden heruntergeladen). 110, 995 (mit SSL)

    2. Postfix – Der E-Mail-Versender¶

    Postfix ist wie ein Postbote, der deine E-Mails versendet.

    • Aufgabe: Nimmt E-Mails entgegen und leitet sie an den Empfänger weiter.
    • Vorteile: Schnell, sicher, einfach zu konfigurieren.

    3. Dovecot – Der E-Mail-Empfänger¶

    Dovecot ist wie ein Briefkasten, in dem E-Mails empfangen und gespeichert werden.

    • Aufgabe: Ermöglicht das Abrufen von E-Mails (z. B. mit Thunderbird oder einem Handy).
    • Vorteile: Unterstützt IMAP und POP3, sicher, effizient.

    4. Wichtige Begriffe¶

    Begriff Erklärung Beispiel
    SMTP-Server Server zum Versenden von E-Mails. Postfix
    IMAP-Server Server zum Empfangen und Verwalten von E-Mails. Dovecot
    Domain Der Name deines E-Mail-Servers. example.com
    MX-Record Zeigt an, welcher Server für E-Mails einer Domain zuständig ist. mail.example.com
    Spam-Filter Filtert unerwünschte E-Mails (Spam) heraus. SpamAssassin

    🎮 Praxis – Postfix und Dovecot installieren¶

    📌 Schritt 1: Postfix installieren¶

    1
2
3
    # Postfix installieren
sudo apt update
sudo apt install postfix -y

    Während der Installation:

    • Wähle "Internet Site".
    • Gib deine Domain ein (z. B. meinmailserver.local oder eine echte Domain, falls vorhanden).

    Postfix starten und aktivieren:

    1
2
3
    sudo systemctl start postfix
sudo systemctl enable postfix
sudo systemctl status postfix

    📌 Schritt 3: Benutzer für E-Mails einrichten¶

    1. Erstelle einen Benutzer (z. B. testuser): 
      1
       sudo adduser testuser
    2. Gib ein Passwort ein (z. B. Test1234!).
    3. Bestätige die weiteren Fragen mit Enter.
    4. E-Mail-Verzeichnis erstellen (für Dovecot): 
      1
2
3
       sudo mkdir -p /home/testuser/Maildir
 sudo chown testuser:testuser /home/testuser/Maildir
 sudo chmod 700 /home/testuser/Maildir

    📌 Schritt 4: Postfix für lokale E-Mails konfigurieren¶

    1. Bearbeite die Postfix-Konfiguration: 
      1
       sudo nano /etc/postfix/main.cf
    2. Füge folgende Zeilen hinzu oder ändere sie: 
      1
2
3
4
5
6
       myhostname = mail.meinmailserver.local
 mydomain = meinmailserver.local
 myorigin = $mydomain
 inet_interfaces = all
 mydestination = $myhostname, localhost.$mydomain, localhost, $mydomain
 home_mailbox = Maildir/
    3. Speichern: Strg + O → Enter → Strg + X.
    4. Postfix neu starten: 
      1
       sudo systemctl restart postfix

    📌 Schritt 5: Dovecot konfigurieren¶

    1. Bearbeite die Dovecot-Konfiguration: 
      1
       sudo nano /etc/dovecot/conf.d/10-mail.conf
    2. Füge folgende Zeile hinzu oder ändere sie: 
      1
       mail_location = maildir:~/Maildir
    3. Speichern und schließen.
    4. Dovecot neu starten: 
      1
       sudo systemctl restart dovecot

    📝 Aufgabe 4: E-Mail zwischen zwei VMs senden¶

    Beschreibung:

      1
       echo "Hallo, das ist eine Test-E-Mail!" | mail -s "Test-E-Mail" emailuser@IP_DER_VM2
    3. Ersetze IP_DER_VM2 mit der IP-Adresse der zweiten VM.
    4. Melde dich auf VM2 als emailuser an und prüfe die E-Mails: 
      1
2

 mail

    Lösung:

    E-Mails abrufen (auf VM2):

    1
2
    su - emailuser
mail
    Befehl zum Anzeigen der E-Mails:

    • mail (nach dem Einloggen als emailuser)

    🎓 Zusammenfassung – das Wichtigste¶

    Thema Was es macht Beispiel
    Postfix Versendet E-Mails (SMTP-Server). sudo apt install postfix
    Dovecot Empfängt und verwaltet E-Mails (IMAP/POP3-Server). sudo apt install dovecot-core
    SMTP Protokoll zum Versenden von E-Mails. Port 25, 587
    IMAP Protokoll zum Empfangen und Verwalten von E-Mails. Port 143, 993
    POP3 Protokoll zum Empfangen von E-Mails (Herunterladen). Port 110, 995
    Maildir Verzeichnis, in dem E-Mails gespeichert werden. /home/benutzer/Maildir

    Merksätze:

    1. Postfix = Versenden, Dovecot = Empfangen.
    2. SMTP = Senden, IMAP/POP3 = Empfangen.
    3. Port 25 = SMTP, Port 143 = IMAP, Port 110 = POP3.
    4. E-Mails werden in /home/benutzer/Maildir gespeichert.
